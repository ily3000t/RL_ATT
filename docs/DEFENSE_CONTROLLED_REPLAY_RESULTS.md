# D1：首次动作偏离与持续攻击的控制性结果

2026-10-07。已完成并独立复核 350 次物理 rollout、150 个攻击配对：Clean/OARL 各五个冻结模型、五个共同开发交通、PGD/预算版 Zero-One Return/Single Return。无攻击条件由三种攻击共用。历史 None 与持续攻击逐步精确复现，单次条件在相同真实动作前缀和可查询 SUMO 状态下仅干预首次动作分歧，再使用实际新访问状态的正常观测。没有训练新防御，没有重新生成攻击，没有使用 Gate 或保留的 split 30。

**主要发现：即时不可恢复的失败与持续攻击造成的额外损害需要分开研究。** OARL 两种搜索的单次碰撞转换均为 5/23，全部来自同一个交通；持续执行后分别变为 11/23 和 8/23。其他交通中单次行为偏离有时提高回报，持续攻击则产生明显损害。不能据此预设“所有偏离都应该惩罚”或“观察恢复后策略仍普遍不会恢复”。

## 三条件的完整比较

## 集中交通的即时失败

交通 `1610385403` 的 reset 在 t=82 秒返回，ego 位于 lane 2；82 次 warmup 调用没有 ego colliding ID。两种搜索在两个策略 cohort 的五个模型上均把首步动作改为 action 1（向左请求 lane 3），命令持续参数为 100 秒。原正常动作随模型不同：Clean seed 2、OARL seed 2/3 是 action 0（向右请求 lane 1），其余是 action 2（不发送换道命令）。单次和持续条件在第一个交互步均观测到 SUMO ego 碰撞及移除，回报为 0；无攻击条件继续存活。因此每种搜索的十个“策略 × 模型”早转换来自**同一个交通状态**，并不需要第二次攻击来触发。

这排除了本次集中早失败“reset 已发生 ego 碰撞”的解释，支持该配置下首次行为选择的因果差异。它不证明现实道路的几何接触、跨交通普遍的即时不可恢复性，或特定防御机制的有效性。SUMO 使用 `collision.action=remove`，ego 消失导致原环境终止；这是保留的原协议。

原始 road 的 lane 声明长度 40,000 m，但 shape 只有 5,000 m，此问题在 [上游审计](OARL_CODE_AUDIT.md) 已记录。此次真实状态再确认：reset 时 Auto/Car.11 的 `getPosition` x 约 0.8805/2.5790，而 `getLanePosition` 约 7.0437/20.6324。两种距离不能混用，更不能从原 16D 中的坐标距离直接恢复真实纵向净间距。原路网与观测保持不变；既有 TTC/DRAC 使用真实 SUMO leader/follower gap，而不是上述坐标差。

## 持续损害与必须保留的反例

OARL Zero-One 与 Single 的持续回报相对单次条件平均进一步降低 36.27、32.45；对应晚转换由单次的 0、0 变为持续的 6、3。两种搜索在该策略上的单次转换全部为集中交通的早失败。其他交通的单次回报并不统一下降：例如 OARL seed 2、交通 `1940738230` 的 Single 对照，无攻击 53.35，单次 154.75，持续 -0.10；该病例自身无攻击已经碰撞，不属于 eligible ASR。OARL seed 3、交通 `1472154258` 则为 174.95 / 176.84 / 69.89，持续条件第 81 个交互步碰撞，单次没有碰撞。

但“延迟碰撞只会来自持续攻击”也不成立。Clean seed 2、交通 `258385557` 的 Single 单次干预在第 22 步碰撞，持续在第 24 步碰撞。PGD 在两个策略的 seed 2、交通 `1610385403` 上，单次均在第 28 步碰撞，持续却没有碰撞。这些都包含在完整统计中。

原 `changeLane` 请求会在指定时长内尝试换道，成功后保持目标车道直到剩余时长结束；后续正常 action 2 不发送取消命令。局部恢复正常输入不等于立即取消 SUMO 请求，也不等于重新回到无攻击访问状态。相关语义核对使用当前安装的 [TraCI 源码](<E:/Program Files/sumo-1.22.0/tools/traci/_vehicle.py>) 与 [SUMO Safety 文档](<E:/Program Files/sumo-1.22.0/docs/userdoc/Simulation/Safety.html>)；默认碰撞定义可能涉及 minGap，不能自动认证物理接触。可查询状态指纹不是隐藏模拟器状态的序列化，本次同 seed/reset/动作前缀及历史精确转移共同支撑比较。

## 对下一步的约束

OARL Robust 继续作为匹配当前任务的强基线。结果支持分别测量首个危险行为与持续损害，并将动作相关长期后果纳入候选目标的核对。它没有证明恢复模块、分支覆盖模块或 ACoE 适配已经有效；尤其不能把所有与正常策略不同的动作标成负例。暂不按集中 traffic 设计规则，不给部署 actor 增加 Gate/取消换道逻辑，不修改老 checkpoint。

下一步先补 D2 的策略快照、恢复一致性与训练/额外数据成本账本；同时完成 [ACoE 离散映射](ACOE_DISCRETE_MAPPING.md) 中仍未解决的即时误差来源、belief 和 off-policy 目标选择。合法仿真分支只提供真实状态中实际动作的后果，不提供任意数值观测候选的 latent reward。母方法与自己的版本必须共享可审计的近似和数据权限；尚不开始母方法或新防御长程训练。
