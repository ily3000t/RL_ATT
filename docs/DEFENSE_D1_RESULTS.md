# D1：防御失败轨迹诊断结果

2026-10-05。已完成全部既有 pilot 的只读诊断：350 个 episode、57,195 个真实交互步，两个策略 cohort、五对训练模型、五个共同交通、七种攻击。没有新的策略前向、SUMO rollout 或训练。OARL Robust 保留为当前 SUMO 换道任务的强基线，以下是其已知边界的诊断证据。

2026-10-07 后续：[控制性回放](DEFENSE_CONTROLLED_REPLAY_RESULTS.md) 已覆盖全部 150 个聚焦攻击配对，新增 350 次诊断 rollout；以下旧只读分析和数值保留不变。新证据排除集中早失败的 reset ego 碰撞解释，并区分单次干预和持续执行损害；候选奖励与母方法训练目标仍待明确。

## 碰撞转换时序

每行受攻击条件有 25 个 episode，但独立交通只有五个。Clean 自身无攻击已有一次碰撞，Robust 已有两次；各自 eligible 分母为 24 和 23。碰撞转换只统计各策略无攻击未碰撞、攻击后碰撞的配对样本。“早”是前三个真实交互步，“晚”是第 21 步及以后；以下转换未出现在第 4–20 步。

| 策略 | 攻击 | 回报 | 总碰撞 | 转换 / eligible | 早转换 | 晚转换 | 同访问状态动作改变率 |

完整结果也包含 None、Random、OARL-BO，不改写已有实验数值。这次补充将总碰撞时序与 eligible 碰撞转换时序分开：Robust 的两种搜索均有 7 次总碰撞在前三步，其中各有 2 次对应自身无攻击已碰撞样本，所以早转换是 5 次，而不是 7 次。

## 交通集中性比原 pooled 数字更重要

两种搜索在 Clean 和 Robust 上的 **全部五次早碰撞转换，都来自同一个交通 seed `1610385403`，分别对应五个训练模型**。它们不是五个独立早失败交通。FGSM/PGD 的早转换也集中在这个交通。不能据此声称即时失败普遍出现，也不能只针对这个 traffic 调整防御。

| 交通 seed | Robust Zero-One 早/晚转换 | Robust Single 早/晚转换 |
| --- | ---: | ---: |
| 1472154258 | 0 / 2 | 0 / 1 |
| 1940738230 | 0 / 0 | 0 / 0 |
| 1610385403 | 5 / 0 | 5 / 0 |
| 258385557 | 0 / 2 | 0 / 2 |
| 2018177452 | 0 / 2 | 0 / 0 |

Robust Zero-One 的六次晚转换全部出现在训练模型 seed 2 和 3，各三次；Single 的三次晚转换分别在模型 seed 2 和 3 出现一次和两次。这里没有重新把训练 seed 与交通绑定；每个模型都在相同五个交通上评估。故失败既有交通集中性，也有模型差异，仍需独立新交通验证。

动作改变次数也不足以代表损害：Robust 的 PGD 动作改变率更高，回报却比 Clean 更高；两种搜索用更少的动作改变步达到较低回报。但这个比例受访问状态与提前终止影响，不能仅凭 pooled 比例断言某个局部目标无效。

## 目标动作与实际行为计划

所有搜索真实执行步的 `planned_action` 均等于日志中的实际动作，共验证 12,824 步。请求目标 `target_action` 则不一定被内层扰动实现：Zero-One 在 Clean/Robust 上分别有 591/455 次请求目标未命中；Single 为 0/3 次。这些步仍拥有与实际执行一致的 witness，不能计为轨迹回放错误。

Robust Single 的三次请求目标未命中都在模型 seed 1：episode 1 的 step 79，episode 2 的 step 161 和 180；请求为右换道 action 0，实际及 witness 为左换道 action 1。这是目标标签与实际可执行行为的差别；本次不修改攻击或重新生成扰动，不将目标命中率当 ASR。正式机制比较继续以实际执行分支和完整资源账本为准。

## 当前可以据此确定的任务

先区分即时行为风险、持续攻击与后续损害，不先固定“覆盖/恢复”模块。下一步控制性诊断应覆盖全部开发配对并分别统计原本无攻击未碰撞样本：从相同真实状态与共同动作前缀，比较正常输入、第一次偏离后恢复正常输入、持续攻击。对集中交通补记 reset 结束时的 ego 状态和碰撞标志，核对前三步的换道命令、SUMO minGap 碰撞与 ego 消失边界。

旧 evaluator 只在真实 step 后采样，未记录 reset 结束时碰撞；所以当前时序不证明第一步碰撞的具体物理原因，也不证明恢复机制不足。晚碰撞发生前仍可能持续受到攻击，首次分歧到碰撞的延迟不是“单次扰动的持续效应”。本轮不提出已经成立的防御创新，不生成最终测试或显著性结论。
